Laboratório de testes e experimentos

Nada vai para produção sem ser provado antes: stack isolada de Trino+Iceberg+Hive Metastore sobe do zero a cada execução de CI, e mudanças arriscadas (permissão de volume, compaction que derrubava o Trino por OOM) foram primeiro reproduzidas manualmente numa rede Docker isolada no próprio servidor, nunca direto em produção.

Servidor Ubuntu — acesso via SSH

ssh dataadm@100.69.31.14 — alcançável só pela rede privada Tailscale do time, nunca exposto à internet aberta. 24h no ar, uso concomitante por toda a equipe — por isso existe uma auditoria de acesso própria (sessão SSH + comando executado, mesmo via sudo).

Colaboração via GitHub

Branches por frente de trabalho, Pull Requests com revisão antes do merge na main, histórico completo de decisão técnica nos commits — inclusive esta própria apresentação, feita slide a slide, cada um com seu PR.

CI/CD

Todo push roda 5 jobs de integração contínua (lint, testes unitários, Spark+Iceberg local, dbt build real contra Trino) — e, só depois de tudo passar num push na main, um job de entrega contínua aplica o código no servidor real via SSH sobre Tailscale, em segundos.
